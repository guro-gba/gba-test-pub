# Leafbound

A small 2D platforming metroidvania for the Game Boy Advance, built with
[Butano](https://github.com/GValiente/butano) (21.9.0). Movement and combat are modeled on
MapleStory: momentum-based jumps, ropes to climb, one-way platforms you can drop through,
melee swings with floating damage numbers, knockback, EXP and levels.

All graphics are placeholder shapes and colors, generated by `tools/gen_assets.py`.

## Controls

| Button | Action |
| --- | --- |
| D-Pad left/right | Walk (in the air you keep your momentum, like MapleStory) |
| D-Pad up/down | Climb ropes; Up at a portal to go through it; Down to crouch |
| A | Jump. Down + A drops through a platform. With Flash Jump, A again in mid-air |
| B | Sword attack (hits the closest enemy in front of you) |
| R | Slash Blast skill: wide wave that hits up to 6 enemies (costs 8 MP) |
| L | Drink a potion (+60 HP) |
| START | Pause |

## The world

Four connected maps, linked by portals:

- **Mossy Meadow**: where you start. Snails, slimes and mushrooms. The chasm to the west needs Flash Jump.
- **Whispering Forest**: a tall climb of platforms and ropes, with the **Flash Jump** feather at the top.
- **Crystal Caves**: bats, spikes and a deep cavern. The **Spring Boots** at the bottom let you climb the
  shaft to the boss.
- **Golem's Hall**: the boss fight. Beat the Golem to win.

There are also three hidden **Heart Crystals** (+25 max HP), one per exploration map, each behind an
ability. Enemies respawn, drop potions and give EXP; leveling up raises HP, MP and attack and fully heals
you. If you fall in battle you wake up in Mossy Meadow and lose 10% of your current EXP.

## Building

1. Clone with the Butano submodule:

   ```sh
   git clone --recurse-submodules https://github.com/guro-gba/gba-test-pub.git
   # or, in an existing clone:
   git submodule update --init
   ```

2. Install a GBA toolchain: [devkitARM](https://devkitpro.org/wiki/Getting_Started)
   (`DEVKITARM` set) or [Wonderful Toolchain](https://wonderful.asie.pl/) (`WONDERFUL_TOOLCHAIN` set),
   plus Python 3.

3. Build:

   ```sh
   make -j$(nproc)
   ```

   This produces `gba-test-pub.gba`, which runs in any GBA emulator (mGBA, NanoBoyAdvance, ...)
   or on hardware via a flash cart.

CI builds the ROM on every push (see `.github/workflows/build.yml`) and uploads it as an artifact.

## Changing the maps or graphics

The map layouts, enemy and item placements, and every sprite live in `tools/gen_assets.py`. It writes
the background images and sprite sheets to `graphics/` and the collision and spawn data to
`src/lb_level_data.cpp`. After editing it, run:

```sh
python3 tools/gen_assets.py
```

The generated files are committed, so building doesn't require running the script.

## Code layout

| File | Contents |
| --- | --- |
| `src/main.cpp` | Title → game → game over / victory loop |
| `src/lb_game.cpp` | The world: map loading, portals, combat, pickups, camera |
| `src/lb_player.cpp` | Player movement, ropes, attacks, knockback |
| `src/lb_enemy.cpp` | Snail, slime, mushroom, bat and Golem behavior |
| `src/lb_physics.cpp` | Tile collision for solid ground and one-way platforms |
| `src/lb_hud.cpp`, `src/lb_fx.cpp` | Status bars, messages and floating damage numbers |
| `src/lb_scenes.cpp` | Title, game over and victory screens |
| `include/lb_stats.h` | Levels, EXP curve, HP/MP and collected items |
